# BOOK 1.0.2

Личная электронная библиотека и PWA-читалка на русском языке. Оптимизирована для iPhone и Safari. Работает без аккаунта, сервера приложений, рекламы и аналитики.

## Обновление 1.0.2 — надёжное открытие книг

Исправлена потеря SVG-обложек при нормализации EPUB. До сохранения проверяются XHTML, manifest/spine, оглавление и доступное содержимое. Reader проверяет реальную видимость текста или декодированного изображения, обрабатывает ошибки разделов и ограничивает ожидание открытия. Вместо пустой области доступны состояния загрузки, ошибки, повторного открытия и восстановления из сохранённого оригинала.

Повреждённая нормализованная копия восстанавливается при открытии конкретной книги. ID, оригинал, пользовательские метаданные, позиции и аннотации сохраняются. Повторный импорт того же SHA-256 тоже обновляет только файл. Fullscreen и настройки 1.0.1 сохранены. [Диагностика, проверенные файлы, тесты и ограничения](docs/QA-1.0.2.md).

## Обновление 1.0.1 — чтение на весь экран

Панели скрыты при открытии книги. Касание центра показывает и скрывает меню поверх страницы, без изменения её размеров. Обычная область чтения использует `100dvh` с fallback для старого Safari, safe area со всех сторон и компактные поля. В настройках Aa доступны пресеты горизонтальных полей, отдельные вертикальные поля, отступ первой строки, переносы и небольшой индикатор прогресса. Сохранённые настройки версии 1.0 сохраняются, новые значения добавляются без сброса размера шрифта.

[Изменения и фактическая проверка 1.0.1](docs/QA-1.0.1.md).

## Возможности

- Импорт настоящих **EPUB 2/3, FB2, FB2.ZIP и TXT**, включая несколько файлов и drag-and-drop на компьютере. SHA-256 предотвращает дублирование файлов.
- Полные «Белые ночи», «Пиковая дама» и «Дама с собачкой» включены в стартовую библиотеку. Их можно удалить.
- Постраничное чтение и вертикальный свиток, оглавление с вложенными главами, поиск по всему тексту, переход по проценту книги.
- Переходы кнопками, касаниями краёв, горизонтальным свайпом и клавиатурой. Касание центра скрывает панели.
- Четыре темы, четыре семейства шрифтов, размер, межстрочный интервал, поля, расстояние между буквами и абзацами, выравнивание, плотность текста и затемнение страницы. Настройки сохраняются.
- Позиция чтения в CFI, восстановление после закрытия и изменения типографики. Закладки, выделения трёх цветов и редактируемые заметки.
- Поиск, сортировка, сетка/список, избранное, статусы чтения и собственные коллекции.
- Локальная статистика активного чтения, недельный график и ежедневная цель.
- Экспорт оригинала без изменения его байтов. Резервная копия `.book`: книги, позиции, коллекции, заметки и статистика. Восстановление объединяет данные с текущей библиотекой.
- Установка на экран «Домой», офлайн-кэш приложения и книг, безопасное обновление приложения по запросу. Опциональный Screen Wake Lock при поддержке браузером.

## Локальный запуск

Требуется Node.js 22.12+ или 24 LTS.

```sh
npm ci
npm run dev
```

Проверка production PWA:

```sh
npm run build
npm run preview
```

Service worker включён в production-сборке. Для установки и офлайн-доступа нужен HTTPS либо localhost. Секреты и переменные окружения приложению не требуются.

## iPhone

1. Откройте опубликованный BOOK в Safari.
2. Дождитесь сообщения о готовности к офлайн-работе.
3. «Поделиться» → «На экран „Домой“» → «Добавить».
4. Импортируйте собственную книгу через «+» из приложения «Файлы».

Учтены `viewport-fit=cover`, safe area, `dvh`, альбомная ориентация читалки и отсутствие принудительного запрета масштабирования. Проверки viewport: 320, 375, 390, **402 × 874**, 430 и 1440 CSS px.

**Хранилище локальное:** библиотека Safari и установленной PWA может быть изолирована операционной системой. Нет автоматической синхронизации устройств. Очистка данных сайта, удаление PWA или решение iOS об освобождении места могут удалить книги. Сохраняйте `.book` через «Настройки → Сохранить резервную копию». Кнопка защиты хранилища запрашивает `navigator.storage.persist()`; решение принимает браузер.

## Проверки

```sh
npm run check
npm test
npm run format:check
npx playwright install --with-deps chromium webkit
npm run build
npm run test:e2e
npm audit --omit=dev
```

Playwright запускает production preview автоматически. `BASE_URL=https://... npm run test:e2e` проверяет опубликованную версию. Для тестового WebKit с нестандартным расположением зависимостей предусмотрен необязательный `BOOK_WEBKIT_EXECUTABLE`; обычному окружению он не нужен.

Сценарии охватывают импорт, ошибки файлов, дедупликацию, оригинальный текст, страницы, типографику, CFI-восстановление, закладки, поиск, выделения с заметками, коллекции, резервную копию, офлайн-перезапуск, свиток, зоны касания и поворот. [Отчёт QA](docs/QA.md).

## Архитектура

- `src/engine/ReaderEngine.ts` — независимый контракт движка.
- `src/engine/EpubEngine.ts` — EPUB.js, CFI, навигация, темы и аннотации.
- `src/engine/importer.ts`, `bookDocument.ts`, `inspection.ts` — кодировки, безопасная нормализация и проверка EPUB, FB2 → EPUB и TXT → EPUB.
- `src/engine/readerHealth.ts`, `readerFailure.ts` — проверка видимого содержимого и ограниченное ожидание стадий открытия.
- `src/lib/bookRecovery.ts` — проверка нормализованной копии и атомарное восстановление из оригинала при открытии.
- `src/lib/readerDiagnostics.ts` — локальные коды и размеры без текста, CFI и сетевой отправки.
- `src/workers/archive.worker.ts` — распаковка с ограничениями вне UI-потока.
- `src/lib/db.ts` — Dexie/IndexedDB; книги, оригиналы и позиции отдельно от UI.
- `src/lib/settings.ts` — Zustand, версионированные локальные предпочтения.
- `src/lib/backup.ts` — переносимый архив и повторный безопасный импорт оригиналов.
- `src/components` — библиотека, читалка, настройки, статистика, заметки и доступные модальные панели.

[Выбор движка, безопасность и расширение](docs/ARCHITECTURE.md).

## Границы версии 1.0.2

Поддерживаются текстовые EPUB с изменяемой вёрсткой, в том числе EPUB3 с NCX или HTML-навигацией. Статические SVG-обложки очищаются и показываются как изображения; SVG-страницы spine получают XHTML-обёртку с тем же местом в последовательности. DRM, PDF, fixed-layout EPUB, аудио/видео, интерактивный JavaScript/SVG, MathML и синхронизация не поддерживаются. Издательские CSS удаляются для единообразной и безопасной типографики; текст, поддерживаемые иллюстрации и локальные ссылки сохраняются. Сложная таблица или нестандартная сноска может требовать другого издания книги.

Лимиты: 50 МБ на оригинал; TXT — 16 МБ; распакованный книжный архив — 100 МБ суммарно, 16 МБ на запись, 4000 записей. Общая резервная копия ограничена 95 МБ исходных данных; большие библиотеки можно переносить частями, сохраняя оригиналы. Восстановление добавляет данные, не очищая текущую библиотеку; при повреждении одного из файлов уже добавленные книги сохраняются.

Реальный iPhone 17 и установка на домашний экран требуют заключительной проверки на устройстве: эмуляция WebKit не проверяет аппаратную частоту дисплея, Dynamic Island, системный файловый диалог и поведение iOS при нехватке места.

## Vercel

`vercel.json` задаёт Vite, `dist`, заголовки безопасности и SPA-маршрутизацию. Используется только проект BOOK, связанный с `elcin31/book`. Достаточно Git-интеграции и `npm ci` → `npm run build`; backend и внешняя БД не нужны.
