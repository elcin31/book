# Стартовая библиотека

Полные оригинальные произведения, первая публикация до 1931 года; авторские тексты находятся в общественном достоянии.

| Книга | Автор | Год | Источник транскрипции |
|---|---|---|---|
| Белые ночи | Фёдор Михайлович Достоевский | 1848 | https://ru.wikisource.org/wiki/Белые_ночи_(Достоевский) |
| Пиковая дама | Александр Сергеевич Пушкин | 1834 | https://ru.wikisource.org/wiki/Пиковая_дама_(Пушкин) |
| Дама с собачкой | Антон Павлович Чехов | 1899 | https://ru.wikisource.org/wiki/Дама_с_собачкой_(Чехов) |

Получено через MediaWiki API 25 октября 2026 года. Участники и история правок доступны по ссылке «История» на каждой странице. Транскрипции предоставляются Викитекой на условиях [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). EPUB представляет собой преобразование HTML в главы и абзацы с нормализацией пробелов, удалением навигационных шаблонов, служебных элементов и маркеров ссылок на примечания. Сведения об атрибуции добавлены в последний раздел каждого EPUB. Скрипт `scripts/build-sample-books.mjs` воспроизводит преобразование с текущими версиями страниц.

Типографические обложки BOOK созданы в CSS; сторонние обложки и изображения не используются. Книги, которые импортирует пользователь, остаются на его устройстве и не публикуются.
