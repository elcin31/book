# BOOK 1.0 — проверка выпуска

Дата: 25 октября 2026. Проверяется production-сборка Vite с реальным service worker, а не dev-сервер и не макеты книг.

## Автоматические проверки

| Проверка | Результат |
|---|---|
| TypeScript strict, `npm run build` | Пройдено |
| Vitest: 11 тестов | Пройдено |
| Playwright: 11 сценариев × Chromium и WebKit | 22 из 22 пройдено, 1,6 минуты |
| `npm audit --omit=dev` | 0 известных уязвимостей |
| Форматирование Prettier | Пройдено |

Модульные проверки: FB2 → полноценный EPUB, автор/название/главы/курсив, отклонение DTD и битого XML, удаление активного HTML и внешних URL, сохранение `epub:type`, ограничения размера, атомарный импорт и дедупликация, EPUB3, синхронный журнал CFI, каскадное удаление книги, повреждённый EPUB, ZIP traversal и ZIP bomb с 17 МБ распакованной записью.

Браузерные сценарии в каждом движке:

1. Настоящий EPUB: исходный текст, перелистывание, тема и шрифт, закладка, поиск по тексту, точное восстановление CFI, холодный запуск без сети.
2. Импорт FB2 с двумя главами, переход между ними, повторный импорт, понятная ошибка повреждённого EPUB.
3. Коллекция, избранное, скачивание `.book`, восстановление в новом browser context, сохранение избранного у уже имеющейся стартовой книги.
4. Библиотека на ширине 320 CSS px без горизонтального переполнения.
5. То же — 375 px.
6. То же — 390 px.
7. То же — 402 × 874 px.
8. То же — 430 px.
9. Desktop — 1440 px.
10. Выделение настоящего текста с заметкой, повторное открытие записи, две последовательные зоны касания справа, режим свитка, поворот 874 × 402 и отображение заметки в библиотеке.
11. Вредоносный EPUB: скрипты и внешние картинки удалены. Отдельная попытка вставить inline script уже после импорта блокируется CSP главы в обоих движках.

## Обнаруженные и исправленные проблемы

- Для коллекций добавлен индекс `createdAt`.
- Устранён повторный `xmlns` при XML-сериализации нормализованного XHTML.
- Оригиналы хранятся как ArrayBuffer: устранена воспроизводимая ошибка WebKit при записи Blob/File в IndexedDB.
- Зоны касания рассчитаны по видимой ширине, а не общей ширине iframe с колонками всей главы.
- Worker не отнимает буфер исходного файла, который нужен для экспорта и копии.
- Начальный service worker получает управление через `clientsClaim`; установка обновления остаётся по запросу пользователя.
- Восстановление копии объединяет коллекции и переносит избранное/позиции даже для дедуплицированных книг.
- WebKit блокирует DOM-события внутри script-disabled iframe. Разрешение trusted controller в sandbox отделено от политики `script-src 'none'` для книги. Нативные обработчики работают; вредоносный код остаётся запрещён. Предусмотрен резервный опрос выделения из родительского окна.
- Убран `content-visibility:auto`, вызывавший различия видимости карточек в WebKit.
- Общая копия содержит оригиналы, а не их дубли. Для неё применяется отдельный лимит распаковки, позволяющий восстановить оригинал более 16 МБ.

## Среда и границы проверки

Headless Chromium 156 и Playwright WebKit 27.2 на Linux. Для WebKit необходимые системные библиотеки размещены только в игнорируемой директории `.qa-libs`; системная установка с root не использовалась. Приложение не зависит от этих QA-файлов.

Проверены браузерные viewport и смена размеров. Реальный iPhone 17 в этой среде недоступен. Перед публичным App Store-подобным позиционированием нужно проверить на устройстве:

- Установку из Safari и standalone-запуск, safe area вокруг Dynamic Island и индикатора жестов.
- Импорт из iCloud Drive / «Файлы» и скачивание копии через системный интерфейс.
- Долгое чтение, смену ориентации и выделение через нативные маркеры iOS.
- Уход в фон, выгрузку процесса и перезапуск в авиарежиме.
- Большую личную библиотеку, Low Power Mode, Wake Lock и заполнение хранилища.
- Профилирование прокрутки и задержек на реальном 120-Гц экране. FPS в автоматических проверках не заявляется.

Нет проверки всей совокупности существующих EPUB/FB2: поддерживается безопасное подмножество reflow EPUB и стандартного FB2. DRM, fixed layout и мультимедиа исключены явно.
